Run DrafNote yourself in 5 minutes.

Free forever. HTTPS-only server, automatic encrypted backups, and a production-ready Gunicorn config. No Docker required, no phone-home.

Quick start ↓ Requirements

Requirements

  • Python 3.10+ (standard library + gunicorn for prod)
  • A machine that's on when you need notes (Pi, NAS, VPS, old laptop)
  • Port 5001 reachable on your LAN
  • Local CA certs included — trust once per client
The server refuses to start without TLS. There is no plain-HTTP mode — by design.

What you get

  • Unlimited notes, sections, vaults & shared workspaces
  • Six themes + reading fonts, synced per device
  • Full-text search, tags, import/export
  • 2FA, passkeys, recovery codes
  • Automatic backups of the encrypted store

Quick start

1
Get the code
git clone <your-drafnote-repo> drafnote
cd drafnote
2
Trust HTTPS (one-time per client)

Server ships with a local CA. Copy certs/drafnote-ca.crt to each device and trust it once — browsers stop showing “Not Secure”.

# regenerate if your LAN IP changes:
./certs/generate-certs.sh 192.168.1.10
3
Run dev
python3 server.py
# → https://127.0.0.1:5001 locally
# → https://192.168.1.10:5001 on LAN
4
Run production (Gunicorn)

Single worker + 8 threads — single worker is load-bearing for live sync streams.

python3 -m gunicorn -c gunicorn.conf.py server:app
5
Verify
curl -sk -o /dev/null -w "%{http_code}\n" https://192.168.1.10:5001/ # expect 200

Create your account → save recovery codes → write your first note.
